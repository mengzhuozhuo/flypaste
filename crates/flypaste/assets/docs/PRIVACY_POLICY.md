# 隐私政策

**生效日期**: 2026年6月19日

欢迎使用 Flypaste。您的隐私对我们至关重要。本隐私政策解释了您在使用 Flypaste macOS 应用程序时，我们如何处理您的数据。

## 1. 数据收集与存储

**我们不收集、传输或共享您的任何个人数据或剪贴板历史记录。**

Flypaste 是一款完全本地化的应用程序。您的所有剪贴板数据（文本、图像、文件）都本地存储在您的 Mac 上，且严格受限于苹果高度安全的 **App Sandbox（应用沙盒）** 环境中。数据永远不会离开您的设备，我们也没有任何服务器来接收您的数据。

## 2. 辅助功能权限

Flypaste 需要 macOS 辅助功能权限（系统设置 -> 隐私与安全性 -> 辅助功能）才能正常运行。

**为什么我们需要此权限：**
我们使用此权限的**唯一目的**是模拟「Command + V」（粘贴）键盘操作。当您从 Flypaste 历史记录中选择一个项目时，应用程序会自动将其粘贴到您当前活动的应用程序中。我们绝对不会使用此权限来监控您的按键（键盘记录）或读取其他应用程序的数据。

## 3. 网络使用

Flypaste 的核心剪贴板管理功能不需要任何互联网连接即可运行。
